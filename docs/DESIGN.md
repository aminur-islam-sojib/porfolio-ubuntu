# DESIGN quick reference

The full design system lives in `.agents/skills/ubuntu-design-system/SKILL.md`. Summary:

- Accent `#E95420`, aubergine backgrounds, dark theme default, light theme via tokens.
- Window radius 12px, title bar 40px, controls right (circles), close orange on hover.
- Top bar 30px near-black; dock on the LEFT, 48px icons, orange running dots.
- Fonts: Ubuntu + Ubuntu Mono. 4px spacing grid.
- Motion: 120/200/320ms, transform and opacity only.

Reference mood: clean Ubuntu 24.04 desktop (GNOME + Yaru). Original wallpapers, icons and branding only.
