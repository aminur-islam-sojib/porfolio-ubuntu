# PRD: Ubuntu Desktop Portfolio

## Vision
A full-stack developer portfolio that feels like a real Ubuntu desktop in the browser: premium, smooth, and memorable, but still fast to navigate for recruiters and clients.

## Goals
1. Wow factor on desktop with an authentic Ubuntu (GNOME/Yaru) feel and a real window manager (drag, resize, snap, minimize, maximize).
2. Excellent tablet and phone experiences through dedicated touch shells.
3. Communicates skills, projects and contact info within 10 seconds.
4. Performance and accessibility that prove engineering quality.

## Non-goals
Real OS emulation, real shell access, copying Canonical branding, auth/backend beyond a contact form.

## Audience
Recruiters, hiring managers, freelance clients, fellow developers.

## Key features
- Boot + lock screen (skippable), top bar, left dock, Activities overview, app grid, desktop icons, context menu, notifications, quick settings
- Window manager with snapping and Alt+Tab
- Apps: About, Terminal, Files, Projects, Browser, VS Code viewer, Settings, Mail, Resume, Trash
- Dark/light themes, accent colors, wallpapers
- Phone shell (launcher + app switcher), tablet shell (dock + split view)
- Classic (plain) view, SEO, deep links, analytics

## Success metrics
Lighthouse 90+/80+, 60fps drag, zero console errors, contact form works, Classic view reachable in one click, all apps usable on 390px width.
